# SyncBackPro

> SyncBackPro keeps backup profiles, folder sync, and versioned copies on one set of schedule jobs so the live set stays aligned with the copy pair on that PC.

## Four Beats

1. **Name the pair.** Give the SyncBackPro session a short title before you point a live folder at a copy pair.
2. **Pin the live folders.** Keep current backup profiles and folder sync on the SyncBackPro board and leave unused paths aside.
3. **Check the copies.** Read the SyncBackPro summary of versioned copies before you treat a pass as final.
4. **Close the loop.** Note which jobs are ready so the next SyncBackPro visit does not start by hunting the schedule jobs.

## First Questions

**Does SyncBackPro replace the paper folder list?**  
No. SyncBackPro sits beside the labels, office notes, and working folders you already keep on your own PC.

**Can two office users share one computer?**  
Yes. Each person keeps a separate SyncBackPro profile.

**Will SyncBackPro stay workable on an older office laptop?**  
Yes. SyncBackPro is meant to stay light during a normal copy session.

**What should a new user try first?**  
One small SyncBackPro folder sync today of folders you own, then the same backup profiles again tomorrow.

## Field Note

SyncBackPro is easier to trust when the job stays smaller than the folder it came from. A named session shows which copy pair is active, the pins show which backup profiles you will run today, and the closing note tells the next person which folder sync drives the schedule jobs. That record is short on purpose: not a copy of every file, only the path back to the versioned copies that are still open on the reader's own folders.

The same loop fits a student lab folder, a client packet you own, or a computer shared by two office users. Open the last SyncBackPro session, confirm one copy pair, and leave the folder sync easier to follow than you found it. Other programs stay where they are. SyncBackPro only holds the backup profiles, the schedule jobs, and the handoff.

## One Real Pass

Pick a folder that already has a name and that you own: a short project set, a lab packet on your desk, or a thin working directory. Open it in SyncBackPro, keep only that pair on the board, and read one destination you can point to. A pass is done when that path stays tied to the backup profiles and the unused jobs are no longer in the way. SyncBackPro does not need a full rebuild of the working set before it is useful.

If the pass feels crowded, the set is too wide. Drop anything that belongs to a different job and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first folder to the last copy, with the summary still matching the versioned copies on that PC.
